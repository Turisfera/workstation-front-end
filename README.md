#  TripMatch – Workstation Frontend (Vue 3)

Frontend desarrollado en **Vue 3 + Vite** para la plataforma **TripMatch**, una herramienta diseñada para agencias de turismo y operadores que permite gestionar consultas, experiencias, reservas y comunicación con clientes dentro del ecosistema **Turisfera**.

Este frontend consume los servicios del backend del proyecto y proporciona una interfaz moderna, rápida y adaptable para el uso en casetas, tiendas o escritorios de trabajo.

---

##  Características principales

- Interfaz construida con **Vue 3 (Composition API)**.
- Ruteo mediante **Vue Router**.
- Integración con servicios REST del backend TripMatch.
- Componentes reutilizables y arquitectura modular.
- Gestión de consultas (queries).
- Gestión de experiencias turísticas ofrecidas.
- Panel para agentes de turismo.
- Autenticación integrada.
- Notificaciones, validaciones y manejo de errores.

---

##  Tecnologías utilizadas

- **Vue 3**
- **Vite**
- **Vue Router**
- **Axios**

---

##  Instalación y Despliegue

Sigue estos pasos para ejecutar el proyecto en tu entorno local:

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/Turisfera/workstation-front-end.git](https://github.com/Turisfera/workstation-front-end.git)
    ```

2.  **Instalar dependencias:**
    ```bash
    npm install
    ```

3.  **Ejecutar en modo desarrollo:**
    ```bash
    npm run dev
    ```
    La aplicación estará disponible generalmente en `http://localhost:5173`.

4.  **Compilar para producción:**
    ```bash
    npm run build
    ```
